# JIVO Dashboard — Railway Deploy Guide

## 3 Steps mein live karo

### Step 1 — GitHub pe upload karo
1. github.com/new pe jaao → new repo banao → naam: `jivo-dashboard`
2. "uploading an existing file" click karo
3. Saari files drag karo (server.js, package.json, .gitignore, public/ folder)
4. "Commit changes" click karo

### Step 2 — Railway pe deploy karo
1. railway.app pe jaao → "Start a New Project"
2. "Deploy from GitHub repo" → apna `jivo-dashboard` repo choose karo
3. Deploy button → 2-3 minute wait karo
4. Settings → Networking → "Generate Domain" click karo

### Step 3 — Link share karo!
Aapko milega: `https://jivo-dashboard-xxx.up.railway.app`
Yeh link WhatsApp/email pe share karo — sab ka data sync rahega!
